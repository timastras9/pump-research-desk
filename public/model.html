Train and publish a new model (on your Mac)

  1. Train: python -m research.train --db artifacts/corpus/launches.db --out artifacts/corpus/train-v4
  2. Export and check it matches: python scripts/export_model.py --run artifacts/corpus/train-v4 --db artifacts/corpus/launches.db --out artifacts/models/model-v4.json
  3. Upload: npx wrangler r2 object put crypto-study-media/models/model-v4.json --file artifacts/models/model-v4.json --remote
  4. Pick it above and press Set active. Roll back any time from the history.

Feedback rows from every run (peak, best exit, timing misses, labels) are in the run JSON; download them to add to the next training run.
